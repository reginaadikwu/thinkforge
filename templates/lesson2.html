Lesson 2

Breaking Problems Into Steps

Welcome back! 👋

In Lesson 1, you learned something important: before solving a problem, you first need to understand it.

But understanding the problem is only the beginning.

When a problem is big, trying to solve everything at once can make things confusing.

So what do programmers do?

They break the problem into smaller, manageable steps.

Let's try something.

Imagine I ask you to clean your room.

You probably wouldn't think: "I need to clean everything at once!"

Instead, you might think:

1. Pick up the clothes.
2. Arrange the books.
3. Put things where they belong.
4. Sweep the floor.

Each step is small. But together, they solve the bigger problem.

That's how programmers think too.

Instead of saying: "I need to build an entire website."

A programmer might break it down into smaller problems:

1. Create the homepage.
2. Add the navigation.
3. Create the learning page.
4. Add the lesson interaction.

Big problem → smaller problems → smaller steps.

Now it's your turn. 🧠

Imagine you want to make a sandwich. Which approach would make more sense?
